# PREREG 101 -- does the galaxy rule's strength grow with well depth? Groups as the check (NOT BLIND -- see below)
Rule (Coalesce): no dark matter, no dark energy, nothing invented. Only: visible stars (starlight x stellar mass-to-light from
star models), measured random speeds, and the galaxy rule (v^4 or sigma^4 = const x G M a0, a0 measured in galaxies).
Not blind: Milgrom 2019 (arXiv:1811.12233) headline was seen before writing this: 56 MK11 groups (sigma ~90-175 km/s) need median
M/L_K = 0.72 under standard a0 (deep-MOND relation M = 81 sigma^4 / (4 G a0)). A row-level transcription via the web tool FAILED a
spot check (its 'log L_K' column reproduced M/L = 1.00 for every group -> not real data) and was DISCARDED.
Stellar M/L_K from star models: 0.6-1.0 (range used; disclosed).
Depth law: a0_eff = a0 x (v2 / v2_gal)^n, depth v2 = v_flat^2 (galaxies) or 2 sigma^2 (groups, clusters); n set so clusters
(Coma: sigma 1000 -> v2 = 2e6) get x5.3 (iteration 94), anchored at the median SPARC galaxy depth.
Prediction for groups: a0_eff/a0 = (v2_grp/v2_gal)^n. Observed: k = 0.72 / (M/L_K stellar) = 0.72-1.2.
Expectation: depth law predicts k ~ 1.5-2 for groups; observed ~1 -> mildly disfavoured. Also: biggest SPARC spirals are as deep
as or deeper than groups and show k ~ 1 (iteration 96). Combined expectation: any rise must be a step between group and cluster
depths (not smooth) -- a step would be 'put in by hand', i.e. excluded by the rule.

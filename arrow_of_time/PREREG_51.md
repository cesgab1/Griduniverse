# Pre-registration, iteration 51 (committed BEFORE running): where could the watermark's eta come from?
Setup (BORROWED, Mukohyama 2009): the frame field has dispersion omega(p); a mode freezes when omega(p_*) = H; its power is
P ~ p_*^3 / omega(p_*). For omega = p^3/M^2 exactly, P ~ M^2: scale invariant in ANY expansion era. Tilt therefore needs either
a constant anomalous exponent z = 3 - eta, or a scale-dependent departure from z = 3.
Derived before running (pen and paper): with epsilon = -dlnH/dlna of the era when modes froze,
  constant z = 3 - eta:    n_s - 1 = -(eta/3) epsilon/(1 - epsilon/3)  (radiation era, epsilon = 2: n_s - 1 = -2 eta),  alpha_s = 0
  crossover omega^2 = p^2 + p^6/M^4 (z=3 phase ending, eta grows as modes freeze closer to M):
                           alpha_s = (4/3) [epsilon/(1 - epsilon/3)] (n_s - 1)  -> radiation era: alpha_s = 8 (n_s - 1) ~ -0.2
Expectations:
 T1 numerical spectra reproduce both formulas (within 5%).
 T2 the crossover route is EXCLUDED by the measured running (ACT DR6: alpha_s = 0.0062 +/- 0.0052) by > 20 sigma.
 T3 the constant-exponent route survives; it needs eta = (1 - n_s)/2 = 0.013-0.017 in a radiation era, i.e. the frame field's
    small-scale spectral dimension d_s = 1 + 3/z = 2.004-2.006, NOT exactly 2. A frame-free causal-set grid gives exactly 2
    (BORROWED), so it cannot be the source -- consistent with the two-sector picture.
 T4 eta itself is NOT derived here (needs a loop calculation); the outcome is a narrowing, recorded as such.

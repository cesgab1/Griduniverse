# RESULT 127: where the matter-excess gap comes from
Prereg: PREREG_127.md. Code: iter127_gap_decomposition.py. Numbers: RESULT_127_numbers.txt.
The '5e9 too small' is not a property of the measured bias; it is set almost entirely by ONE premise:
the temperature at which matter number could still change.
| creation temperature | measured bias (PDG masses) | gap |
|---|---|---|
| 160 GeV | 4.3e-22 | 1e12 |
| 131 GeV | 4.8e-21 | 1e11 |
| 100 GeV (used before) | 1.2e-19 | 5e9 |
| 50 GeV | 5.0e-16 | 1e6 |
| 18 GeV | 1.1e-10 | ~6 |
| 16 GeV | = needed | none |
Premise ledger (powers of ten of the gap each controls):
- P1 temperature: everything. Bias falls as 1/T^12; at ~16-18 GeV the measured bias would suffice.
  WHY 100+ GeV is assumed: the process that changes matter number ('sphaleron') is predicted to switch off below
  ~130 GeV once the Higgs field sets in. Sphalerons follow from the structure of the Standard Model but have never
  been observed directly; the switch-off temperature comes from lattice computer simulations. -> premise, not data.
- P2 masses at creation energy: makes gap ~60x LARGER (masses shrink at high energy).
- P3 the 1/T^12 formula is only valid when all quark masses << T; at 16-18 GeV top and bottom are not, so the
  'closing temperature' is suggestive, not a calculation. A real calculation there is needed.
- P4 'started with zero excess' (rests on inflation having erased any initial excess): if false, the whole gap goes.
- P5 'out of balance': the lattice says the transition was smooth -> supply ~0, independent of P1-P3.
- Bookkeeping (eta vs n_B/s): ~1 power of ten only.
Expectations: P1 carries the gap, closes at ~15-25 GeV: HIT (16-18). P2 enlarges gap: HIT.

LESSON 127: the measured particle/antiparticle bias is not '5 billion times too small' in itself. It is too small
ONLY IF matter was made above ~130 GeV, and that timing rests on an unobserved process (sphalerons) plus two other
premises (zero start, out-of-balance). The gap is a statement about premises P1, P4, P5 -- each is a test target.

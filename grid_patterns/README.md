# Chladni check: could a vibrating grid have arranged matter into a regular pattern?
A standing vibration of the grid that gathers matter on its quiet lines (nodes) would leave a preferred spacing L. In the
galaxy power spectrum P(k) that shows up as extra wiggles with period ~2 pi/L (a regular lattice gives a series of them,
like the single BAO wiggle from early-universe sound waves). Searches for exactly this kind of signal exist ('linear
oscillations', P(k) -> P(k)[1 + A sin(omega k + phi)]; omega ~ the spacing).
Published limits (arXiv:2504.06183, BOSS full shape + Planck, 95% CL):
| data | spacing probed (omega) | amplitude A |
|---|---|---|
| galaxies (BOSS) | ~2-22 Mpc/h | < 0.031 |
| CMB (Planck) | (wide range) | < 0.019 |
| combined | | < 0.022 |
Log-spaced oscillations: A < 0.021 (combined). No detection.
Reading: on 2-22 Mpc/h scales a grid node pattern can carry at most ~2-3% of the matter power, i.e. its density contrast is
<~ 15-17% of the ordinary fluctuations there. The only established preferred scale is BAO (~150 Mpc), which standard
early-universe sound waves already explain. The 1990s 128 Mpc periodicity claim (pencil beams) was not confirmed by wide
surveys.
Conclusion: if the grid vibrates, it doesn't arrange matter into a noticeable regular pattern on 2-150 Mpc scales. Any
Chladni-type ordering must be weak (< ~3% of the power), random-phase (indistinguishable from ordinary fluctuations), or on
scales outside these ranges (inside galaxies, or beyond ~1 Gpc). Inside galaxies it remains a possible form for the missing
dissipation channel, but only if the energy loss itself is supplied (khronon_dynamics section 9-10).

# Working model of gravity -- measured inputs only (Coalesce rule: no invented numbers, no unmeasured entities)
Rule: every number is measured; where the model falls short, the shortfall is RECORDED as a measured gap with its domain,
never filled by an assumed substance, field or constant. No Planck scale, no black-hole or Big-Bang interior claims.

## Layer 1 -- the law (Newton's engine + tested add-ons)
acceleration = sum over visible masses of G M / r^2
  + motion/energy corrections (size v^2/c^2, GM/rc^2)   -- measured: Mercury, GPS, Cassini light delay
  + light bends 2x the Newton value                      -- measured: 1919 onward, Cassini 2e-5
  + changes travel at c                                  -- measured: binary pulsars, GW170817 (1e-15)
  + outward push growing with distance (Lambda c^2 r/3)  -- measured value from expansion; cause NOT assumed
Inputs: G (lab, 22 ppm), c (exact), visible mass (light: stars, 21-cm gas, X-ray gas), Lambda (measured number).
Valid, no gap: lab (to ~50 micrometres) and solar system (to ~1e-9 or better); anywhere visible pull > ~1e-9 m/s^2.

## Layer 2 -- measured gaps (data, not explanations)

## What the model deliberately does NOT contain
No dark-matter particle, no modified-gravity formula, no Planck-length grid, no vacuum-energy value: each would be a
number put in for something unknown. Their place is taken by the measured gap tables above.

## What it predicts (no new numbers)
1. Any new disk galaxy: its rotation from its visible matter alone, to ~x1.4 (galaxy gap curve).
2. Any new cluster: pull > galaxy curve by x1.6-3.4 depending on radius.
3. Any new collision: the gap follows the stars.
4. Solar system / lab: Layer 1 exactly, no gap, down to ~1e-9 m/s^2 visible pull.
Open measurement (would test whether the gap depends on the source's own pull): lab masses below ~1e-10 m/s^2 (expedition leg 2).

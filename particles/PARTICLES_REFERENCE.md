# What we know about the particles (reference, Oct 5 2026; values PDG-level, rounded)

## The electron
| property | value | note |
|---|---|---|
| mass | 0.51099895 MeV (9.109e-31 kg) | from the Higgs interaction |
| charge | -1 e (exact, same for all electrons) | |
| spin (intrinsic angular momentum) | 1/2 (hbar/2) | built in; NOT a spinning ball (a ball of electron size would need surface speeds > c) |
| orbital angular momentum | 0 when free and at rest; quantised (0, 1, 2 ... hbar) in atoms | |
| magnetic moment g/2 | 1.00115965218059(13) | most precise property of any particle (2023); matches theory to ~1e-12 |
| size | none found; < ~1e-19 m | behaves as a point in every collider test |
| electric dipole (shape) | < 4.1e-30 e cm (2023) | perfectly round to extreme precision |
| lifetime | stable; > 6.6e28 years (Borexino) | |
| Compton time / size | 1.29e-21 s / 3.86e-13 m | its quantum 'clock' and 'size' |
| antiparticle | positron (same mass, opposite charge) | |
| fermion | obeys Pauli exclusion: no two in the same state (chemistry exists because of this) | |

## The photon
massless (< 1e-18 eV); charge 0 (< ~1e-35 e); spin 1, only two polarisations; speed c; stable; carries the electromagnetic force.

## The full Standard Model (17 kinds)
| family | particles (mass) | spin | charge |
|---|---|---|---|
| charged leptons | electron 0.511 MeV, muon 105.7 MeV (lives 2.2 us), tau 1777 MeV (2.9e-13 s) | 1/2 | -1 |
| neutrinos | three types; masses tiny (splittings 8.6 and 50 meV; sum < ~0.07 eV) | 1/2 | 0 |
| up-type quarks | up 2.2 MeV, charm 1.27 GeV, top 172.6 GeV | 1/2 | +2/3 |
| down-type quarks | down 4.7 MeV, strange 93 MeV, bottom 4.18 GeV | 1/2 | -1/3 |
| force carriers | photon (0), gluon x8 (0), W 80.4 GeV, Z 91.2 GeV | 1 | 0 / +-1 |
| Higgs | 125.2 GeV | 0 | 0 |
Quarks are never seen alone (confined in protons, neutrons, etc.). Proton 938.3 MeV (99% binding energy), stable (> ~1e34 yr);
neutron 939.6 MeV, free lifetime ~880 s.

## Open puzzles about particles
- Why these masses (electron 3.5e5 x lighter than top; hierarchy vs Planck 2.4e22).
- Why three families; why neutrinos are so light; matter-antimatter imbalance.
- Neutron lifetime: bottle ~878 s vs beam ~888 s (unresolved ~4 sigma).
- Dark matter: not any known particle.
- Gravity: no quantum particle (graviton) observed.

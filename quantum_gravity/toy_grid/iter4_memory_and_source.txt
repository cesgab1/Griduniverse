C. Consequences for the relic scalar s:
   * Inflation (required by the model) dilutes any earlier relic to nothing, and a conformal field is not made by
     inflation itself. So s must be made at reheating (inflaton -> s) and THERMALISE itself (e.g. a lambda_s s^4 self-
     coupling, which is conformal). Its temperature is then set by the inflaton's branching ratio, NOT by contact with
     ordinary matter: iteration 3's 'Delta N_eff = 0.027-0.057' holds only if s also shared a temperature with ordinary
     matter. In general 0 < Delta N_eff < 0.107, i.e. T_s/T_nu < 0.66. The amplitude change is absorbed in
     the (already free) size of dark energy. PREDICTION WEAKENED: Delta N_eff > 0, size not fixed.
   * Fifth force: with a symmetry s -> -s (and conformal coupling to curvature), s has no LINEAR coupling to matter, so
     no long-range fifth force at tree level. Contact with ordinary matter via a Higgs portal lambda s^2|H|^2 would give s
     a mass ~ sqrt(lambda) x 246 GeV; staying massless enough for horizon-scale noise (m_s << kappa H0 ~ 1e-32 eV) needs
     lambda << 2e-87, far too weak ever to thermalise. So: NO Higgs-portal contact -> s is a separate
     dark radiation, consistent with the general 0 < Delta N_eff < 0.107.
   * Naturalness: a scalar lighter than 1e-32 eV is as unprotected as a quintessence field (same open problem).

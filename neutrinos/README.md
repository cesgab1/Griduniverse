# Iteration 67: does dark energy set the lightest neutrino's mass? (pre-registered: PREREG_67.md)
Rule (stated first): the lightest neutrino's pop (hbar/mc) holds exactly its own rest energy in dark energy ->
m c^2 = (rho_DE (hbar c)^3)^(1/4) = 2.24 meV. Results (iter67_neutrinos.txt):
- Normal ordering: 2.2 / 8.9 / 50.1 meV, sum 61.3 meV -- inside today's window (58.7 oscillation minimum, 64.2 DESI+CMB bound). PASS.
- Inverted ordering: sum 102 meV -> excluded -- BUT the inverted ordering is excluded by DESI for ANY lightest mass (minimum 99.5),
  so 'predicts normal ordering' is not special to this rule (correction to expectation E2).
- Look-elsewhere: today's data allow any lightest mass below 4.3 meV; 66% of a broad prior passes. The pass is WEAK.
- The h-version (8.9 meV, not registered) would be excluded (sum 72 meV) -- shows the factor convention matters.
Verdict: consistent, not evidence. What would make it real: a measured lightest mass or sum near 61 meV with ~1 meV precision
(not foreseeable), or a model reason that ALSO fixes something else (e.g. the neutrino mass varying with Claim 1's dark energy:
+1.7% at the z ~ 0.7 peak -- far below any measurement). Inference about 'why dark energy has its size': none yet.

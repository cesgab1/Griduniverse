# Expedition: work backwards from 'gravity is simply stronger' (Coalesce)
Exploratory -- descriptive mapping and test planning, NOT a pre-registered test.

## Leg 1 (leg1_boost_map.py/.txt): how much stronger would gravity have to be, with no unseen matter?
- 2803 rotation-curve points, 175 SPARC galaxies: boost x1.0 where visible pull > 1e-9 m/s^2, x1.5 at 1e-10, x3.1 at
  1e-10.75, x7.8 at 1e-11.75. Sorted by pull, scatter 0.15 dex; sorted by distance, 0.27 dex -> the boost follows how WEAK
  gravity is, not how far away you are.
- Lab x1.00000, solar system x1 (strong pull) -- consistent with the pattern.
- Coma x8.3 at 4.5e-12 -> ~1.4x above the galaxy trend; Bullet x5.3 AND in the wrong place for any visible-matter rule;
  early universe x6.4 needed before any galaxy existed (light-ignoring head start). Pattern covers galaxies, not all.

## Leg 2: two ways 'stronger gravity at weak pull' could work, and where each can be caught
H_total: boost set by the TOTAL pull at a place (incl. Earth, Sun, galaxy) -- MOND with 'external field effect'.
H_self:  boost set by the SOURCE's OWN pull, ignoring the background.
| test | H_total predicts | H_self predicts | status |
| lab small masses (Westphal 2021, 90 mg, own pull ~1e-9) | x1 (Earth's 9.8 m/s^2 dominates) | x1.05 | G confirmed to ~10% (memory) -> not decisive |
| next-gen lab: 1 mg at 5 mm (own pull ~3e-12) | x1 | x~7 | feasible extension; would decide H_self |
| gravity-entanglement experiments (1e-14 kg at 0.2 mm, own pull ~2e-17) | x1 | x~2600 -> entanglement 2600x faster | proposed, not yet done -- doubles as a quantum test |
| wide binary stars (Gaia, mutual pull ~1e-10, galaxy ~2e-10) | x~1.2-1.4 | x~2 | contested (Chae vs Banik); Gaia DR4 expected late 2026 (memory) |
| Sun-Earth saddle point | odd tidal stress in a ~100s km zone | none special | proposed for LISA Pathfinder, never flown |
| long-period comets (Sun's pull ~1e-10 at 7000 AU) | changed orbits | changed orbits | published comet analysis argues against MOND (memory, verify) |
Neither H fixes the Bullet's location or the early-universe head start: gravity-only ideas must still answer those.
